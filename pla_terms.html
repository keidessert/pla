TERMS OF SERVICE

利用規約

制定日：2026年11月21日

PASSION to LOGO ALCHEMIST（以下「PLA」といいます。）は、PLAが提供するロゴ制作支援サービス（以下「本サービス」といいます。）について、以下のとおり利用規約（以下「本規約」といいます。）を定めます。

第1条（本サービスの目的と内容）

  1. 本サービスは、依頼者自身が事業への情熱、理念、想いなどをもとにロゴを考案し、創作することを目的とした個別支援サービスです。
  2. 本サービスでは、依頼者がロゴの創作主体となり、PLAはデザインに関する専門知識の提供、助言、技術的な制作、データ作成、調整および仕上げを担当します。
  3. 本サービスは、一般的なロゴ制作代行や、Adobe Illustrator等の操作方法を習得するための講座ではありません。
  4. 依頼者自身が考え、選択し、判断する過程を大切にし、依頼者が自ら生み出したという実感と愛着を持てるロゴの完成を目指します。

第2条（申込みおよび契約の成立）

  1. 本サービスの利用を希望する方は、PLAが指定する申込フォームから必要事項を送信するものとします。
  2. PLAは申込み内容を確認し、承諾する場合は、申込者に対して電子メールその他の方法で承諾の通知を行います。
  3. 本サービスの利用契約は、PLAが申込みを承諾した時点で成立します。
  4. 申込者は、申込みにあたり、本規約の内容を確認し、同意するものとします。
  5. PLAは、申込内容に虚偽や不備がある場合、本サービスの提供が困難と判断した場合など、合理的な理由がある場合には申込みを承諾しないことがあります。

第3条（料金および支払い）

  1. 本サービスの利用料金は、以下のとおりとします。
    • 本体価格：200,000円
    • 消費税：20,000円
    • 合計：220,000円（税込）
  2. 依頼者は、制作完了後、PLAが指定するSTORESの決済ページを通じて利用料金を支払うものとします。
  3. PLAは、決済の完了を確認した後、完成データの納品を行います。
  4. 決済に必要な手数料等が発生する場合は、事前に依頼者へ案内します。
  5. 追加の制作や当初の契約範囲を超える作業が必要となる場合は、事前に内容および料金について協議し、依頼者の同意を得るものとします。

第4条（サービスの進行と依頼者の協力）

  1. 本サービスは、依頼者との対話、ヒアリング、検討および制作支援を通じて進行します。
  2. 依頼者は、自身の事業内容、理念、想い、ロゴに込めたい意味などについて、可能な範囲で正確な情報を提供するものとします。
  3. 依頼者は、ロゴの創作主体として、自ら考え、具体的な表現を生み出し、選択および判断を行うものとします。
  4. PLAは、専門的な知識や経験に基づく助言を行い、依頼者の考えを整理するための質問や情報提供を行います。
  5. 制作の進行にあたっては、双方が協力し、必要な確認や意思決定を行うものとします。
  6. 制作期間は、依頼内容、検討の進行状況および依頼者の対応状況によって異なるため、一律の期間を定めません。

第5条（ロゴの創作主体および制作工程）

  1. 本サービスにおいて、ロゴの創作主体は依頼者とします。
  2. 依頼者は、ロゴの根幹となる主形状について、自ら発想し、具体的な形状を考案し、決定するものとします。
  3. PLAは、依頼者に代わって主形状を考案したり、完成した主形状を一方的に提示して選択させたりすることを、本サービスの通常の制作工程として行いません。
  4. PLAは、依頼者自身が考案した形状について、デザインとしての成立性、視認性、バランス、使用上の適切性などの観点から助言を行うことができます。
  5. 依頼者が決定した形状をもとに、PLAはIllustrator等を使用した技術的なデータ作成、線や比率の調整、配置、仕上げなどを行います。
  6. PLAは、依頼者の意思決定を尊重し、依頼者の承諾なくロゴの根幹となる創作的表現を独自に変更または決定しません。
  7. 依頼者が主形状を自ら考案・決定することが困難な場合は、PLAは質問や助言による支援を行います。ただし、依頼者に代わって主形状を創作することは本サービスの範囲に含みません。
  8. 依頼者が自らの創作主体として制作を進めることができない場合、双方で進行方法を協議し、必要に応じて本サービスの終了について協議するものとします。

第6条（納品物）

  1. PLAは、本サービスの完成時に、以下のデータを納品します。
    • Adobe Illustrator形式（AI）
    • PDF
    • JPG
    • 背景透過PNG
    • PLA ORIGINAL LOGORIA（PDF）
  2. PLA ORIGINAL LOGORIAは、完成したロゴに込められた想いやデザインの意味、制作者である依頼者の名前などを記録するPLA独自の文書です。
  3. LOGORIAは、PLAが発行する独自の記録文書であり、公的な認証、著作権登録、商標登録または法的な権利証明を行うものではありません。
  4. 納品は、STORESのダウンロード販売機能等を利用して行います。
  5. 納品データの利用方法や保管については、依頼者自身の責任で管理するものとします。

第7条（調整および追加対応）

  1. 本サービスには、完成に必要な範囲での調整および仕上げが含まれます。
  2. 依頼者は、制作途中および最終確認時に、ロゴの内容を確認し、必要な意見や修正希望を伝えるものとします。
  3. 当初の方向性から大きく変更する場合や、当初の契約範囲を超える追加制作が必要となる場合は、双方で内容、料金および進行方法を協議するものとします。
  4. 追加対応は、依頼者の同意を得たうえで実施します。

第8条（途中解約および精算）

  1. 依頼者は、本サービスの完了前であっても、PLAに申し出ることにより契約を解約することができます。
  2. 途中解約の場合、PLAは、解約時点までに完了したサービス段階に応じて、以下の金額を精算対象とします。
段階完了条件精算額（税込）
① ヒアリング・理解依頼者の情熱、事業内容、ロゴに込めたい想いを聞き取り、内容を整理した時点33,000円
② 構想・検討ロゴの方向性を検討し、依頼者が選択・決定した時点66,000円
③ ロゴの具体化決定した方向性に基づくロゴのデータ作成が完了した時点77,000円
④ 仕上げ・完成最終調整、確認およびLOGORIAの作成が完了した時点44,000円
合計220,000円
  1. 精算は、各段階のサービスが完了した場合に限り対象とします。着手しただけで未完了の段階については、精算対象としません。
  2. 解約時点で完了している段階までの金額を合算し、依頼者に請求します。
  3. 依頼者は、PLAが指定する方法および期限に従って精算金額を支払うものとします。
  4. PLAの責めに帰すべき事由によってサービスの継続または完成が困難となった場合は、双方で状況を確認し、未完了部分の料金や返金について誠実に協議します。
  5. 本条は、消費者契約法その他の強行法規に基づく依頼者の権利を制限するものではありません。

第9条（著作権および知的財産権）

  1. 本サービスは、依頼者自身が創作主体となることを前提としたサービスです。
  2. 依頼者が自ら創作したロゴの具体的な表現について、著作権法上の著作者となるために必要な創作行為を依頼者自身が行うものとします。
  3. 依頼者が創作した表現に関する著作権その他の知的財産権は、法令に従い、依頼者に帰属します。
  4. PLAは、依頼者の意思を技術的に具体化するためのデータ作成、調整および仕上げを担当し、依頼者に代わって創作的表現を生み出すことを本サービスの目的としません。
  5. PLAが制作過程で著作権法上保護される独自の創作的表現を加えた場合、その表現に関する著作者および権利の帰属は、実際の創作への関与に基づき法令に従って判断されます。PLAは、そのような表現を完成ロゴに取り入れる必要が生じた場合、事前に依頼者へ説明し、取扱いについて協議するものとします。
  6. 本サービスにおいて、PLAから依頼者への著作権譲渡を当然の前提とはしません。
  7. PLAが保有する既存のノウハウ、制作技術、テンプレート、一般的なデザイン手法などに関する権利は、引き続きPLAまたは正当な権利者に帰属します。
  8. 第三者が権利を有するフォント、素材、画像その他の要素を使用する場合は、それぞれの利用条件に従うものとします。

第10条（商標登録等について）

  1. PLAは、完成したロゴについて、商標登録の可能性、登録の可否または他者の権利との抵触を保証するものではありません。
  2. 商標登録の調査、出願および登録手続きは、本サービスには含まれません。
  3. 依頼者が商標登録を希望する場合は、必要に応じて弁理士等の専門家に相談するものとします。
  4. 依頼者は、ロゴの使用にあたり、第三者の著作権、商標権その他の権利を侵害しないよう確認するものとします。

第11条（禁止事項）

依頼者は、本サービスの利用にあたり、以下の行為を行ってはなりません。

  1. 虚偽の情報を提供する行為。
  2. 第三者の著作権、商標権、肖像権その他の権利を侵害する行為。
  3. PLAまたは第三者に対する誹謗中傷、迷惑行為、業務妨害。
  4. 本サービスを通じて取得したPLAの非公開情報や資料を、許可なく第三者に公開または提供する行為。
  5. その他、法令または公序良俗に反する行為。

  1. PLAは、本サービスの提供にあたり取得した依頼者の個人情報を、別途定めるプライバシーポリシーに従って適切に取り扱います。
